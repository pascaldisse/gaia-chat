Delete All Personas Except GAIA

Two Ways to Delete Personas:

  1. Using Developer Overlay (Recommended):
    • Go to your Gaia Chat app
    • Press the backtick key (`) to open Developer Overlay
    • Click "Delete All Personas Except GAIA" button
  2. Using This Page:
    • Click the button below to run the cleanup

What this will do:

  • Delete all personas except GAIA (the default persona)
  • This includes: oldraj, Succubus, ProfessorEinstein, ChefMario, CodeWizard, DDNarrator, and any others
  • GAIA will remain as the only persona
